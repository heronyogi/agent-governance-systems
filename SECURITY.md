# Security policy

## Scope

Agent Governance Systems is a public catalog and federation contract. It is not
a runtime orchestrator, production authorization service, certification
program, or security boundary.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting channel when available. Do not
open a public issue containing credentials, private data, unpublished blind
cases, private correspondence, or private derivation machinery.

## Public-data boundary

- Register public, synthetic, or deliberately disclosed system artifacts only.
- Never place production credentials, personal data, or sealed cases in a
  manifest, gate, trial packet, or result.
- Keep source commits, digests, interface versions, and observation boundaries
  exact; a catalog record must not overstate the underlying repository claim.
- Do not use trial fixtures against systems you do not own or control.

## Bounded claims

Catalog validation proves only that checked-in records satisfy the public
federation schemas and cross-artifact invariants. Registration, a passing trial,
or a merged gate does not certify production safety, transfer authority between
systems, or validate any private ontology.
